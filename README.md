
# Gesture Control AI

AI-powered touchless human-computer interaction system using Computer Vision and MediaPipe.

## Features

- Virtual Mouse Control
- Left Click Gesture
- Right Click Gesture
- Scroll Up / Down
- Screenshot Capture
- Real-Time Hand Tracking
- Hand Skeleton Visualization

## Technologies Used

- Python
- OpenCV
- MediaPipe
- Pynput
- MSS

## How to Run

```bash
pip install -r requirements.txt
python main.py
=======
